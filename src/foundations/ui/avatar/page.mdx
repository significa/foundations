## Anatomy

```tsx
<Avatar>
  <Avatar.Image />
  <Avatar.Fallback />
</Avatar>
```

## API Reference

### Avatar

Extends the `div` element. Pass `label` (or `aria-label`) to name the avatar (`role="img"`). Without it the avatar is
`aria-hidden`, which suits the common case where the name is already text next to it. The image
and the initials are always hidden from assistive tech.

<PropsTable
  definition={{
    label: {
      type: "string",
    },
    size: {
      default: '"md"',
      type: ['"2xs"', '"xs"', '"sm"', '"md"', '"lg"', '"xl"', '"2xl"', '"3xl"'],
    },
    variant: {
      default: '"circle"',
      type: ['"circle"', '"square"'],
    },
  }}
/>

### Avatar.Image

Extends the `img` element, without `alt` (the avatar's `label` names it). Unmounts if the image
fails to load, so the fallback shows.

<PropsTable
  definition={{
    src: {
      type: "string",
    },
  }}
/>

### Avatar.Fallback

Extends the `div` element.

<PropsTable
  definition={{
    children: {
      type: "string",
    },
  }}
/>

### Avatar.Group

Renders direct `<Avatar>` children in an overlapping stack. Each non-leading avatar is cut by an SVG mask that follows the previous avatar's variant (`circle` / `square`) and size, leaving a transparent gap. Children that aren't `<Avatar>` are filtered out — wrap them only at the leaf level.

Extends the `div` element. No custom props. A group usually has no names next to it, so give each
avatar a `label`; otherwise the whole group is hidden from assistive tech.
