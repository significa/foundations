## Anatomy

```tsx
<Listbox value={value} onChange={onChange}>
  <Listbox.Trigger />
  <Listbox.Options>
    <Listbox.Search>
      <MagnifyingGlassIcon />
      <Listbox.SearchInput />
    </Listbox.Search>
    <Listbox.Option />
    <Listbox.Divider />
    <Listbox.Option />
    <Listbox.Empty />
  </Listbox.Options>
</Listbox>
```

## Features

- **Keyboard Navigation**: Use arrow keys to navigate between options, Enter to select, and Escape to close
- **Search Functionality**: A search input that keeps keyboard navigation while filtering options
- **Multiple Selection**: Support for selecting multiple options with checkboxes
- **Custom Rendering**: Flexible API for custom option rendering
- **Form Integration**: Works seamlessly with form libraries
- **Accessibility**: Full ARIA support and keyboard navigation
- **Floating UI**: Smart positioning that adapts to available space

### Listbox.Trigger

Extends the `button` element. A long value truncates. In a flex row, give the trigger's `flex-1` wrapper `min-w-0`: a flex item won't shrink below its content by default, so a long value would widen the row.

### Listbox.Divider

A horizontal line to separate groups of options.

### Listbox.Search

Extends the [`Popover.Search`](/ui/popover#popoversearch) component.

The search header: a bottom divider around an icon and `Listbox.SearchInput`.

### Listbox.SearchInput

Extends the [`Popover.SearchInput`](/ui/popover#popoversearchinput) component.

An input for filtering options. Focus stays in it while the arrow keys move the highlight; pressing Enter selects the highlighted option. Put it in a `Listbox.Search` with an icon; swap the icon for a `Spinner` while results load, and set `aria-busy` on the input then.

```tsx
<Listbox.Search>
  {isLoading ? <Spinner size="sm" /> : <MagnifyingGlassIcon weight="bold" />}
  <Listbox.SearchInput aria-label="Search" aria-busy={isLoading || undefined} />
</Listbox.Search>
```

### Listbox.Empty

A styled container for empty state messages.

## Accessibility

The Listbox component follows the [WAI-ARIA Listbox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/). It includes proper ARIA attributes and keyboard navigation support.

### Keyboard Interactions

- `Space` or `Enter`: Select the focused option
- `ArrowUp` / `ArrowDown`: Navigate between options
- `Home` / `End`: Jump to first/last option
- `Escape`: Close the listbox
- `Tab`: Move focus to the next focusable element
- `Type`: Jump to options starting with the typed characters
