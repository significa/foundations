## Other styles

A project should keep **one** spinner style. `Spinner` ships the ring because that's what Button, Popover and Toaster use; if your project wants a different look, pick one recipe below and replace the contents of `spinner.tsx` with it. Each recipe has the same API (`size`, `label`, `className`) and carries its own keyframes in a React `<style>` tag, so there's nothing to add to your global CSS. React 19 hoists that `<style>` into the head and dedupes it by `href`, so any number of spinners share one copy; keep it in the component rather than lifting it out.

The previews below import the recipe file; in a project, that file replaces `spinner.tsx`.

### Frames

Steps through glyphs, terminal-style. The frames sit in a column behind a one-row window and move with `translateY` and `steps()`, so the animation runs in CSS and doesn't freeze when the main thread is busy, as a `setInterval` would. Under reduced motion it holds the first frame and pulses. Braille is the default; pass any glyphs as `frames`, or change the default to your set.

<SourceCode file="src/foundations/ui/spinner/examples/spinner-frames.tsx" />

```tsx
<Spinner frames={["🌑", "🌒", "🌓", "🌔", "🌕", "🌖", "🌗", "🌘"]} />
<Spinner frames={["|", "/", "-", "\\"]} />
```

## Best Practices

1. **Usage**:
   - Reach for a spinner when all you can say is "something is happening" for a second or more. For known progress use [Progress](/ui/progress); when you know the shape of what's loading use [Skeleton](/ui/skeleton). See [Loading States](/guides/loading-states).
   - The box is fixed and the spinner is vertically centred, so it can sit inline with text without shifting it.

2. **Accessibility**:
   - Pass `label` (e.g. `"Loading results"`) when the spinner is the only sign of the wait: it renders as visually hidden text inside a `role="status"`. Assistive tech may not announce a status when it first appears, so for a wait that must be heard, announce it from a live region that is already on the page. Leave `label` out when the surrounding element already announces it, so screen readers don't hear "loading" twice.
   - Under `prefers-reduced-motion` the ring stops rotating and pulses slowly instead: it still reads as busy, without the motion. The pulse animates `opacity`, so a spinner you hide with `opacity-0` also needs `motion-reduce:invisible` (or unmount it instead).
