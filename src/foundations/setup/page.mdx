## Prerequisites

- A [React 19](https://react.dev/blog/2024/12/05/react-19) project.
- [Tailwind 4](https://tailwindcss.com/) installed and configured.

> We are using React 19. If you still on 18, please check the [React 19 migration guide](https://react.dev/blog/2024/04/25/react-19-upgrade-guide).  
> A few common changes are:
>
> - `ref` is now a prop like the others, so we don't need to use `forwardRef`.
> - `<Context>` as a provider: You can now render `<Context>` as a provider instead of `<Context.Provider>`.
> - `use` can be used instead of `useContext`.
> - `MutableRefObject` is now `RefObject`.
>
> It's possible to use these components in React 18, but you will have to adapt the code as needed.

Install the core dependencies:


## Imports Setup

Foundations imports with a `#/` alias and real file extensions (`#/foundations/ui/button/button.tsx`). Map the alias in `package.json`:

```json
{
  "imports": {
    "#/*": "./src/*"
  }
}
```

This assumes a bundler compiles your TypeScript: a project emitting with `tsc` can't use `#/` imports, since `rewriteRelativeImportExtensions` only rewrites relative specifiers. TypeScript 6.0 or later resolves `#/` imports with `moduleResolution` set to `bundler` or `nodenext`, and needs `allowImportingTsExtensions` (which requires `noEmit`) to accept `.ts`/`.tsx` extensions. [@significa/ts-standards](https://github.com/significa/ts-standards) 0.2.3 or later already sets both; otherwise add them to `tsconfig.json`:

```json
{
  "compilerOptions": {
    "allowImportingTsExtensions": true,
    "noEmit": true
  }
}
```
